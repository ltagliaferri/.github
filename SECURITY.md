# Security Policy

## Reporting a vulnerability

Please report security issues privately rather than in a public issue.

If the repository has private vulnerability reporting enabled, use the
**Report a vulnerability** button under its **Security** tab. Otherwise,
contact the maintainer, [@ltagliaferri](https://github.com/ltagliaferri),
through the contact options on their GitHub profile.

Please include the affected repository, a description of the issue, and steps
to reproduce it if you can. These are personal and research projects maintained
on a best-effort basis, so there is no guaranteed response time.
